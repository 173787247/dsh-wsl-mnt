# dsh-wsl-mnt

DeepSeek Harness 插件：当会话工作区落在缓慢的 /mnt/c 时告警，并建议改用 Linux 家目录路径。

配套 **[dsh-wsl-kit](https://github.com/173787247/dsh-wsl-kit)**。

[English → README.md](./README.md)

## 安装

```sh
dsh plugin --profile web add github:173787247/dsh-wsl-mnt
```

重启 `dsh web` 并开**新**会话。工具名：`mnt_doctor`。
